# AI Cold Email Agent

A production-ready AI-powered cold email agent that automates the process of generating and sending personalized cold emails for job applications.

## Features

- 📄 Resume parsing with PDF support
- 🔍 Job description parsing from text or URLs
- 📊 ATS score analysis
- 🤖 AI-powered email generation using Groq Llama 3.3
- 📧 Gmail integration for sending emails
- 💾 SQLite database for history tracking
- 🎨 Streamlit dashboard for easy interaction

## Tech Stack

- **Backend**: Python 3.12+
- **Frontend**: Streamlit
- **AI**: Groq API (Llama-3.3-70B-Versatile)
- **Database**: SQLite
- **Email**: Gmail API (OAuth2)
- **Parsing**: pdfplumber, BeautifulSoup4, trafilatura
